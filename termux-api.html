Termux-API: o celular inteiro dentro do terminal

Até aqui o Termux era "só" um Linux no bolso. A Termux-API transforma o terminal numa ponte para o hardware e os dados do Android: bateria, SMS, GPS, contatos, câmera, lanterna, notificações. Nesta aula você instala o pacote termux-api na máquina da Ana (ana@android) e começa a consultar o celular por linha de comando — o que abre caminho para scripts que reagem ao mundo real.

Você vai aprender
  • Instalar o pacote termux-api e entender o app Termux:API (o "braço" no Android);
  • Dar as permissões certas nas configurações do Android (sem elas, tudo dá erro);
  • Ler a bateria com termux-battery-status (JSON com "level": 87 e "status": "Charging");
  • Ler SMS com termux-sms-list, GPS com termux-location e contatos com termux-contact-list;
  • Enviar notificações com termux-notification --title ...;
  • Um mapa de todos os comandos termux-* disponíveis.

Os dois lados da Termux-API

A Termux-API tem duas partes que precisam estar instaladas: o pacote termux-api dentro do Termux (que instala os comandos termux-*) e o app Termux:API no Android (que acessa de fato o hardware e os dados do celular). É o app que recebe as chamadas e responde — por isso, se um comando responde permission denied ou not found, quase sempre o app está faltando ou sem permissão. No simulador da Ana, as duas partes já estão no lugar:

$ pkg install termux-api
The following NEW packages will be installed:
  termux-api
0 upgraded, 1 newly installed, 0 to remove.
Setting up termux-api (0.50.1) ...
termux-api instalado ✓

Num celular real, depois do pkg install termux-api, você instala o app Termux:API pela mesma fonte do Termux (F-Droid) — nunca pela Play Store, que tem uma versão quebrada — e concede as permissões em Configurações → Apps → Termux:API → Permissões (SMS, localização, contatos, câmera, lanterna...). Cada comando pede a permissão correspondente na primeira vez.

Erro real de iniciante: rodar termux-battery-status sem o app Termux:API instalado (ou sem a permissão concedida) devolve erro em vez de dados. Se um comando termux-* "não existe" ou recusou acesso, verifique o app e as permissões antes de culpar o Termux — no simulador isso já está configurado, então dá para praticar tranquilo.

Bateria: termux-battery-status

O primeiro comando clássico é ver a bateria do próprio celular pelo terminal — útil para scripts que decidem se dá para rodar um backup pesado agora ou é melhor esperar o carregador:

$ termux-battery-status
{
  "level": 87,
  "status": "Charging",
  "temperature": 31.5,
  "plugged": "AC",
  "health": "Good"
}
level
porcentagem atual da bateria (no exemplo, 87) — é o campo que você mais vai usar em scripts.
status
Charging (carregando), Discharging (na bateria) ou Full.
temperature
temperatura da bateria em °C — acima de ~40 °C o Android começa a limitar a carga.
plugged
onde está ligado: AC, USB ou Wireless.
health
saúde da bateria (Good, Dead, Overheat...).

A saída é JSON puro, então dá para tratar com qualquer linguagem instalada (python, node) ou com jq — por exemplo, um script que só roda o backup quando "status": "Charging", para não drenar a bateria do celular no meio da rua.

SMS e contatos: termux-sms-list e termux-contact-list

Com a permissão de SMS concedida, o terminal lê as mensagens — imagine um script que avisa no Telegram quando chega um SMS do banco, ou que procura o código de verificação automaticamente:

$ termux-sms-list
[{"number":"+5511999887766","body":"Seu código é 123456"},{"number":"+5511912345678","body":"Entrega confirmada"}]
$ termux-contact-list
[{"name":"Mãe","number":"+5511999887766"},{"name":"Max","number":"+5511912345678"}]

Ambos devolvem um array JSON: cada SMS vem com number e body; cada contato, com name e number. Dá para cruzar os dois — ler os SMS e trocar o número pelo nome do contato — usando um script em python, já que o Termux traz o python instalável com um comando (revise pkg se precisar).

Permissão de SMS e privacidade: ler SMS e contatos expõe dados pessoais. No Android 14, o Termux:API precisa das permissões de SMS e Contatos liberadas nas configurações do app — e scripts que enviam SMS (ex.: termux-sms-send) podem gerar custo na sua operadora. Use com responsabilidade, só em celular de uso pessoal.

Localização: termux-location

Com o GPS (ou a rede) ligado, o comando devolve a posição atual do celular em JSON — a base de automações do tipo "quando eu chegar em casa, avisar no grupo da família" (combine com termux-notification e um laço em script):

$ termux-location
{
  "latitude": -23.5505,
  "longitude": -46.6333,
  "altitude": 760.0,
  "provider": "gps"
}
latitude / longitude
coordenadas em graus decimais — no exemplo, o centro de São Paulo (-23.5505, -46.6333).
altitude
altura em metros sobre o nível do mar (760.0).
provider
quem forneceu a localização: gps, network ou passive.

Notificações: termux-notification

Quer que o celular te avise de algo mesmo com o Termux fechado? O termux-notification cria uma notificação de verdade na barra de notificações do Android — ideal para o fim de um backup longo, um job agendado ou um servidor que caiu:

$ termux-notification --title Oi
Notificação enviada (simulada): Oi ✓
$ termux-notification --title "Backup pronto" --content "backup concluido as 03:00"
Notificação enviada (simulada): Backup pronto --content backup concluido as 03:00 ✓

Você controla título (--title), conteúdo (--content), prioridade, som e até ações. No Android 13+, o app Termux:API precisa da permissão de notificações — sem ela, o comando roda mas nada aparece na barra.

termux-info: a identidade do celular pelo terminal

Antes de automatizar qualquer coisa, vale saber em que aparelho o script está rodando — celular novo, Android atualizado, CPU diferente muda o comportamento. O termux-info resume o dispositivo num relatório:

$ termux-info
TERMUX_VERSION=0.118.0
ANDROID_VERSION=14
CPU: Snapdragon 8 Gen 2
RAM total: 8 GB
Storage: 128 GB
Shell: /data/data/com.termux/files/usr/bin/bash
Device: Pixel 7 Pro (rooted)

Repare que ele já entrega o essencial para um script: versão do Android (ANDROID_VERSION=14), CPU (Snapdragon 8 Gen 2), RAM (8 GB) e o modelo (Pixel 7 Pro). Dá para usar num script de diagnóstico que você manda para um amigo quando ele diz "no meu celular não funciona": rode termux-info e termux-battery-status e mande as duas saídas.

JSON na prática: lendo a bateria com python

Como a saída dos comandos termux-* é JSON, o passo natural é processar com uma linguagem. Com o python instalado (pkg install python → Python 3.11.9), um script de 3 linhas decide se roda o backup ou espera o carregador:

#!/data/data/com.termux/files/usr/bin/python3
import json, subprocess

bateria = json.loads(subprocess.check_output(["termux-battery-status"]))
print("nivel:", bateria["level"], "| status:", bateria["status"])

if bateria["status"] == "Charging" and bateria["level"] > 80:
    subprocess.run(["~/backup.sh"])   # só faz backup pesado com bateria cheia na tomada
else:
    print("deixa o backup pra depois...")

Esse é o poder da Termux-API: o terminal deixa de ser só um lugar para ver dados do celular e passa a agir sobre eles. A mesma ideia vale para SMS (termux-sms-list + procurar o código de verificação), localização (termux-location + comparar com as coordenadas de casa) e contatos.

Versão certa do app Termux:API: a Play Store tem um app "Termux:API" antigo e quebrado — instale o Termux e o Termux:API pela F-Droid (mesma fonte recomendada na aula de instalação). Se um comando diz not found mesmo com o pacote instalado, a causa quase sempre é o app errado ou a permissão desligada.

Resumo

  • A Termux-API tem duas partes: o pacote termux-api (comandos no Termux) e o app Termux:API (acesso ao Android) — instale os dois pela F-Droid.
  • Cada comando precisa da permissão correspondente nas configurações do app Termux:API; erro de permissão é o erro mais comum.
  • termux-battery-status devolve JSON com "level": 87 e "status": "Charging" — ideal para condicionar scripts.
  • termux-sms-list, termux-contact-list e termux-location devolvem arrays/coordenadas em JSON, prontos para processar com python.
  • termux-notification --title ... cria notificações de verdade na barra do Android.
