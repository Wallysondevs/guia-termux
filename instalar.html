Instalar certo: F-Droid, não a Play Store

A instalação do Termux tem um erro clássico: procurar "Termux" na Play Store e instalar o primeiro resultado. Essa versão está desatualizada desde 2022 e quebrada em Androids recentes — e o pior: parece que instalou, mas não funciona direito. Nesta aula você aprende as fontes confiáveis (F-Droid e GitHub), instala também o Termux:API (app separado!), dá as permissões que o Android pede e valida tudo com pkg update e pkg list-installed.

Você vai aprender
  • Por que a Play Store está fora: targetSdk antigo, app abandonado lá desde 2022.
  • As fontes oficiais: F-Droid (recomendado) e as releases no GitHub (termux/termux-app).
  • Que o ecossistema tem vários apps: Termux, Termux:API, Termux:Styling, Termux:Widget, Termux:Boot — todos no F-Droid.
  • Instalar o pacote termux-api dentro do Termux para os comandos termux-* funcionarem.
  • As permissões que o Android mostra (storage, notificações, segundo plano) e o que cada uma libera.
  • Validar a instalação: pkg update, pkg list-installed e o erro de pacote inexistente.

Por que a Play Store está fora

Em 2022 o Google Play passou a exigir que apps mirassem uma versão recente da API do Android (targetSdkVersion). O Termux publicado na Play Store tinha parado de ser atualizado (o projeto migrou para o F-Droid e o GitHub porque lá dá para usar as APIs que o Play restringe). Resultado: em Androids novos, a versão da Play Store instala mas quebra — ou nem aparece na busca.Muita gente trava aí e desiste do Termux achando que "não funciona no meu celular".

Regra de ouro: Termux e os apps da família vêm do F-Droid (f-droid.org) ou das releases oficiais no GitHub (github.com/termux/termux-app/releases). Nunca de APK solto na internet — app de terminal com código modificado é porta aberta para roubar suas senhas.

Passo a passo na máquina da Ana

Na Pixel 7 Pro com Android 14, a Ana fez assim:

  1. Baixou o cliente do F-Droid em f-droid.org (o APK oficial) e instalou permitindo "instalar deste fonte" só na hora.
  2. No F-Droid, procurou Termux e instalou. O F-Droid avisou que é a mesma assinatura do projeto oficial — bom sinal.
  3. Abriu o Termux pela primeira vez: o app rodou pkg update sozinho na primeira inicialização para preparar os repositórios.
  4. Voltou no F-Droid e instalou o Termux:API — app separado, que dá os comandos termux-battery-status, termux-sms-list, termux-camera-photo…
  5. Dentro do Termux, instalou o pacote correspondente: pkg install termux-api.
  6. O Android mostrou a caixa de diálogo de permissões — a Ana aceitou as que fazem sentido (detalhadas abaixo).
$ pkg install termux-api
The following NEW packages will be installed:
  termux-api
0 upgraded, 1 newly installed, 0 to remove.
Setting up termux-api (0.50.1) ...
termux-api instalado ✓
pkg
O gerenciador de pacotes do Termux (aula pkg e apt detalha).
install
O subcomando "instalar".
termux-api
O nome do pacote — é o lado de dentro do app Termux:API; sem esse pacote os comandos termux-* respondem "command not found".
Os dois lados da Termux-API precisam casar: o app Termux:API (instalado pelo F-Droid, dá o acesso ao hardware) e o pacote termux-api (instalado com pkg dentro do Termux, dá os comandos de terminal). Muita gente instala só o app e acha que o termux-battery-status está quebrado — na verdade faltou o pacote.

As permissões que o Android vai pedir

O Android isola cada app, então o Termux precisa pedir permissão para sair da própria sandbox. These são as principais:

Acesso a fotos/arquivos (storage)Ler e gravar em ~/storage (DCIM, Download…)termux-setup-storage — aula storage

A regra prática: conceda a permissão quando o comando pedir e o Android mostrar o diálogo. Se você negar, o comando falha na hora — nada quebra, só não funciona.

Valide a instalação: seus primeiros comandos de diagnóstico

Com tudo instalado, a Ana rodou dois comandos para confirmar que o gerenciador de pacotes está saudável. O primeiro atualiza a lista de pacotes dos repositórios do Termux:

Missão: digite pkg update e aperte Enter. A última linha deve ser Reading package lists... Done — é a lista de repositórios atualizada.

$ pkg update
Get:1 https://packages.termux.dev/apt/termux-main stable InRelease
Reading package lists... Done
Building dependency tree... Done

O segundo lista o que já está instalado — cada linha termina com [installed]:

Missão: rode pkg list-installed. Procure o sufixo [installed] em cada linha — é assim que o Termux marca pacote instalado.

$ pkg list-installed
python/stable 3.11.9-2 [installed]
nodejs/stable 20.11.1 [installed]
openssh/stable 9.6p1 [installed]
vim/stable 9.1.0 [installed]
nano/stable 7.2 [installed]
sqlite/stable 3.45.1 [installed]
curl/stable 8.6.0 [installed]
git/stable 2.44.0 [installed]

Na máquina real da Ana a lista é bem maior; no simulado aparecem os primeiros 8. Repare no formato de cada linha: nome/stable versão [installed] — stable é o canal do repositório termux-main.

E quando o pacote não existe?

Se você digitar um nome errado, o erro é claro:

$ pkg install pacote-que-nao-existe
Unable to locate package pacote-que-nao-existe
"Unable to locate package" não é culpa sua — acontece quando (a) o nome está errado, (b) você não rodou pkg update ainda, ou (c) o pacote só existe em repositório extra (x11-repo, unstable). A saída certa é rodar pkg search termo para achar o nome exato antes de instalar — a aula pkg e apt cobre isso.

Cuidados depois de instalar

Com o Termux no ar, três hábitos evitam dor de cabeça:

  • Mantenha atualizado: rode pkg update && pkg upgrade toda semana (ou antes de instalar algo novo). Pacotes do Termux são compilados para o Android atual — ficar para trás quebra instalações.
  • Não confunda com root: o Termux roda como usuário comum (u0_a231). Se um tutorial mandar sudo, no Termux não existe — e não precisa: a casa dele já é só dele.
  • Cuide das configurações: o arquivo ~/.termux/termux.properties muda fonte, cores e teclas extras do teclado virtual. Antes de mexer, copie o original: cp ~/.termux/termux.properties ~/.termux/termux.properties.bak.
  • Repositórios extras existem (x11-repo para interface gráfica, unstable, root-repo) — só adicione com pkg install x11-repo quando um pacote específico exigir; não precisa para este guia.
$ pkg update && pkg upgrade
Get:1 https://packages.termux.dev/apt/termux-main stable InRelease
Reading package lists... Done
Reading package lists... Done
0 packages upgraded, 0 newly installed.
Se o pkg update der erro de rede (sem internet, DNS bloqueado, operadora com proxy), o Termux continua funcionando com a lista antiga — mas instalações novas podem falhar com Unable to locate package. Conecte no Wi-Fi e rode pkg update de novo.

Resumo

  • Nunca da Play Store: a versão de lá está parada desde 2022 e quebra em Androids novos. Use F-Droid ou as releases do GitHub (termux/termux-app).
  • A família Termux tem vários apps: Termux (terminal), Termux:API, Termux:Styling, Termux:Widget, Termux:Boot — todos no F-Droid.
  • A Termux-API precisa dos dois lados: o app (F-Droid) e o pacote pkg install termux-api dentro do terminal.
  • Permissões (storage, notificações, SMS, GPS, câmera…) são pedidas pelo Android na hora do uso — conceda quando fizer sentido para o comando.
  • Valide com pkg update (Reading package lists... Done) e pkg list-installed (linhas com [installed]).
  • Erro clássico: Unable to locate package X → rode pkg update e pkg search X para achar o nome certo.
