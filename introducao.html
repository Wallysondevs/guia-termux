O que é o Termux — e por que usar no celular

O seu celular Android já roda Linux por baixo — o kernel é Linux. O que faltava era uma porta para ele: um terminal de verdade. É isso que o Termux instala: um app que cria um ambiente Linux completo num diretório privado (/data/data/com.termux), com shell bash, hundreds de programas instaláveis com pkg e acesso aos sensores do aparelho via Termux-API. Neste guia você vai usar tudo isso na máquina fictícia ana@android — um Pixel 7 Pro com Android 14 — direto no navegador.

Você vai aprender
  • O que é o Termux de verdade: bash real, /data/data/com.termux, repositórios e pacotes próprios (sem root!).
  • Os casos de uso que fazem sentido no celular: servidor, desenvolvimento, automação, labs.
  • A máquina deste guia: ana@android — Pixel 7 Pro, Android 14, Snapdragon 8 Gen 2, 8 GB de RAM e um dispositivo rootado visível via adb.
  • A anatomia do prompt ana@android:~$ e os comandos básicos de orientação (whoami, pwd, ls).
  • A diferença entre o app Termux, o app Termux:API e o perigo da Play Store (próxima aula).
  • Seu primeiro contato com o terminal simulado deste guia: adb devices e termux-battery-status.

Um Linux de bolso, sem root

Quando você instala um app normal no Android, o sistema cria um usuário Linux só para ele e uma pasta privada. O Termux faz exatamente isso — mas em vez de uma interface gráfica, ele te entrega um terminal Linux completo nessa pasta:

$ pwd
/data/data/com.termux/files/home
$ ls
backup.sh  storage  .bashrc  .termux  projetos
$ echo $SHELL
/data/data/com.termux/files/usr/bin/bash

Repare nos detalhes: o home da Ana não é /home/ana como no PC — é /data/data/com.termux/files/home, dentro da área privada do app. Os programas ficam em /data/data/com.termux/files/usr/bin (o Termux usa o prefixo usr dentro do próprio diretório). E o shell é um bash de verdade, com histórico, autocompletar com Tab, atalhos de teclado e scripts.

Isso significa que quase tudo que você aprende de Linux no PC funciona no Termux: pipes (|), redirecionamento (>), grep, tar, ssh, python, git… A diferença é que aqui roda no celular, na bateria, na rede Wi-Fi da sua casa.

Termux não precisa de root — e não ganha root sozinho. O app roda como um usuário normal do Android (no caso da Ana, u0_a231), então ele não mexe no sistema fora da própria pasta. Isso é bom para segurança, mas limita algumas coisas (portas abaixo de 1024, acesso a pastas de outros apps). Neste guia o celular da Ana é rootado, então mais tarde você vai conseguir enxergar o sistema por fora via adb — veja a aula adb: contrôler o celular pelo PC (com root).

O fio condutor deste guia: você vai transformar o celular da Ana num pequeno servidor de bolso, controlado pelo terminal — primeiro do próprio celular, depois pelo PC via SSH e adb.

Anatomia do prompt

Toda sessão de terminal mostra um prompt antes de cada comando. No Termux da Ana ele é assim:

ana@android:~$
ana
O usuário logado — a conta do app Termux no Android (o sistema chama ela de u0_a231, como você vê com whoami).
@
Separador: "usuário arroba máquina".
android
O nome da máquina (hostname) — neste guia, sempre android.
:
Separa a máquina da pasta atual.
~
A pasta atual: ~ é o atalho para a home (/data/data/com.termux/files/home).
$
O símbolo de usuário comum. Se vir # no lugar, a sessão está como root.

Experimente agora: o terminal simulado

Cada aula deste guia tem uma caixa de terminal simulada (igual à do início) que imita o Termux da Ana no navegador. Ela entende os comandos reais do Termux: pkg, termux-*, sshd, adb, sqlite3 e os básicos de shell. Se não lembrar de nenhum, digite help.

Comece vendo que o celular da Ana está rootado e visível via adb:

Missão: digite adb devices e aperte Enter. Você deve ver o serial R5CT20ABCPIXEL e a linha Dispositivo rootado detectado ✓.

$ adb devices
List of devices attached
R5CT20ABCPIXEL	device product:blueline model:Pixel_7_Pro device:blueline

Dispositivo rootado detectado ✓ (1 dispositivo)

Agora veja a bateria do aparelho — a Termux-API devolve um JSON:

Missão: digite termux-battery-status e encontre no JSON o campo "level": 87 (87% de bateria, carregando na tomada).

$ termux-battery-status
{
  "level": 87,
  "status": "Charging",
  "temperature": 31.5,
  "plugged": "AC",
  "health": "Good"
}

Esses dois comandos mostram as duas pontas deste guia: o adb fala com o sistema do Android por fora, e o termux-* fala com os sensores do aparelho por dentro do Termux. O nível 2 inteiro é dedicado à Termux-API.

Família Termux: vários apps, um ecossistema

O projeto Termux não é um app só — é uma família de apps que se conversam:

AppPara que serveInstala como
TermuxO terminal + ambiente Linux (este guia inteiro)App normal (F-Droid recomendado)
Termux:APIOs comandos termux-* (bateria, SMS, GPS, câmera, lanterna…) que falem com o AndroidApp separado + pacote pkg install termux-api
Termux:StylingTemas e fontes para o terminalApp separado, opcional
Termux:WidgetAtalhos na tela inicial que rodam scriptsApp separado, opcional
Termux:Boot / TaskerRodar comandos ao ligar o celular / por gatilhosApps separados, nível avançado
Não instale o Termux pela Play Store. A versão da Google Play está desatualizada desde 2022 e quebrada em Androids novos (o Google mudou a política de targetSdkVersion e o app antigo parou de funcionar / foi removido). A fonte correta é o F-Droid ou as releases no GitHub — a próxima aula, Instalar certo (F-Droid, não a Play Store), mostra o passo a passo.

Termux não é a única opção — e é a mais leve

Existem outros jeitos de ter Linux no Android, mas quase todos são pesados ou complicados:

OpçãoComo funcionaPesoQuando faz sentido
TermuxAmbiente nativo compilado para Android (sem máquina virtual), dentro do próprio appLeve (~100 MB + pacotes)Sempre que possível — é o padrão deste guia
proot-distroUma distro Linux inteira (Ubuntu, Debian…) rodando em cima do Termux via proot (sem root real)MédioQuando você precisa de apt completo de desktop (nível 2)
UserLAnd / AndronixApps que instalam uma distro via proot ou VMMédio/pesadoAlternativas prontas, mas menos flexíveis
Máquina virtual (QEMU/limbo)Um computador inteiro emulado dentro do celularPesado (GBs, lento)Testes de imagens de PC, quase nunca no dia a dia

O Termux ganha porque não emula nada: os programas são compilados para rodar nativamente no processador do celular (ARM), direto no Android. É por isso que um pkg install python termina em segundos e o Python abre na hora.

O sistema de arquivos que você vai usar

Dentro do Termux, a home da Ana tem esta cara:

$ ls -la ~
drwx------ 5 u0_a231 u0_a231 4096 backup.sh
drwxrwxr-x 2 u0_a231 u0_a231 4096 storage
drwx------ 3 u0_a231 u0_a231 4096 .termux
drwxr-xr-x 4 u0_a231 u0_a231 4096 projetos
-rw------- 1 u0_a231 u0_a231  220 .bashrc
  • ~/backup.sh e ~/backup.log — o script de backup que a Ana agenda (você verá em automação);
  • ~/storage — a ponte para as fotos e arquivos do celular (aula termux-setup-storage);
  • ~/.termux — configurações do próprio Termux (fonte, teclas, cores);
  • ~/projetos — onde ela guarda os códigos que desenvolve no celular;
  • ~/.bashrc — script que roda toda vez que um terminal abre (personalizações).

Resumo

  • O Termux é um terminal Linux real para Android: bash em /data/data/com.termux/files, sem precisar de root.
  • Casos de uso reais no celular: servidor (sshd, web), desenvolvimento (python, node, bancos), automação (cron) e controle do aparelho via Termux-API.
  • A máquina deste guia é ana@android: Pixel 7 Pro, Android 14, 8 GB de RAM, com um caminho rootado via adb.
  • O prompt ana@android:~$ mostra usuário, máquina, pasta atual (~ = home) e o $ de usuário comum.
  • Cada aula traz um terminal simulado no navegador: adb devices mostrou o Pixel rootado e termux-battery-status mostrou "level": 87.
  • Termux:API é um app separado + pkg install termux-api; e a instalação certa vem do F-Droid, nunca da Play Store.
