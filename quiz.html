Olhe o placar lá no topo. Acertou tudo? Ótimo — volte para a cola de comandos termux-* sempre que precisar no dia a dia. Errou alguma? Cada parte acima tem os links das aulas correspondentes — revise só o que travou, sem culpa: errar no quiz é de graça.

Quiz não é nota, é bússola: cada erro aqui é um conceito que ainda não assentou — e agora você sabe exatamente em qual página do guia ele mora.

Gabarito comentado

  1. F-Droid — a Play Store tem o Termux desatualizado; baixe de fdroid.org. (aula: instalar certo)
  2. pkg update + pkg search — lista nova e nome exato (nodejs, openssh…). (ref-pkg)
  3. termux-setup-storage + aceitar a permissão no Android → ~/storage lista as pastas. (storage / ref-erros)
  4. Porta 8022: ssh ana@192.168.1.42 -p 8022. (sshd)
  5. adbd já como root no Pixel rootado; adb shell whoami → root. (ref-adb)
  6. sshd rodando + IP atual (ifconfig) — Connection refused quase sempre é sshd parado. (problemas)
  7. termux-api (pacote) + Termux:API (app com permissões). (termux-api / ref-termux)
  8. Ubuntu via proot, sem root real no Android. (proot-distro)
  9. Wake lock segura a tela; unlock libera (senão drena bateria). (wake lock)
  10. ngrok = túnel público para o servidor local do celular. (rede no celular)
