Cola de pkg / apt — instalar programas no celular

O pkg é o gerenciador de pacotes do Termux — um apt modificado que baixa programas já compilados para Android do repositório packages.termux.dev e instala em $PREFIX (/data/data/com.termux/files/usr). É com ele que o celular vira servidor: python, git, nmap, postgresql, nginx… Nesta cola estão os subcomandos que você vai usar todo dia, com a saída real de cada um na máquina da Ana.

Você vai aprender
  • A regra de ouro: pkg update antes de qualquer instalação, sempre.
  • Os 7 subcomandos: update, upgrade, install, search, list-installed, show, uninstall/remove.
  • pkg e apt são sinônimos no Termux — dá para usar qualquer um.
  • O erro Unable to locate package X: nome errado ou lista de pacotes desatualizada.
  • Quais pacotes o simulador conhece (python, nodejs, openssh, vim, nmap, termux-api, ngrok…).

O que é o pkg, por baixo do capô

Num Linux de PC você usa apt e instala em /usr/bin. No Termux não existe permissão para escrever em /usr (o Android tranca o sistema), então o Termux criou o $PREFIX: um diretório privado do app, /data/data/com.termux/files/usr, que funciona como se fosse a raiz /. Quando você instala o python, o binário vai para $PREFIX/bin/python — e o $PREFIX/bin já está no PATH, por isso o comando funciona na hora.

$ pwd
/data/data/com.termux/files/home
$ echo $PREFIX
/data/data/com.termux/files/usr
$ ls
backup.sh  storage  .bashrc  .termux  projetos

O repositório oficial é o termux-main stable (você vê ele na saída do pkg update), mantido pela comunidade em packages.termux.dev — os pacotes são compilados especialmente para rodar no Android, com patches quando preciso.

Procurar antes de instalar: search e show

Esqueceu o nome exato? O pkg search lista os pacotes que casam com o termo e o pkg show traz a ficha técnica antes de instalar:

$ pkg search vim
vim/stable 9.1.0 vim
$ pkg search ng
ngrok/stable 3.12.1 ngrok
$ pkg show git
Package: git
Version: 2.44.0
Maintainer: Termux
Description: pacote do repositório Termux (simulado)
$ pkg search abacate
No matches found for abacate

Repare no No matches found for abacate: quando o search não acha nada, o install também não vai achar — e aí vem o erro clássico:

$ pkg install abacate
Unable to locate package abacate
Unable to locate package X — as duas causas: (1) o nome está errado (confira com pkg search — às vezes é nodejs, não node; openssh, não ssh); (2) a lista de pacotes está velha — rode pkg update primeiro. Se mesmo assim não achar, o pacote pode não existir para Termux (muitos programas de PC não têm build para Android).

Atualizar e remover: upgrade e uninstall

$ pkg upgrade
Reading package lists... Done
0 packages upgraded, 0 newly installed.
$ pkg uninstall vim
Removing vim ...
vim removido.
$ pkg install vim
Setting up vim (9.1.0) ...
vim instalado ✓
$ vim notas.txt
(simulado) editor vim aberto — :q para sair 😄

O pkg upgrade é o "manter o celular atualizado": depois de um pkg update, ele troca os pacotes instalados pelas versões novas do repositório. O pkg uninstall (ou pkg remove, sinônimo) desinstala — útil quando um pacote quebra outro ou você não usa mais.

Não use apt install às cegas no Termux real: o apt existe como apelido do pkg, mas instalar pacotes do repositório errado (ex.: o repositório do sistema do Android) quebra o ambiente. Prefira sempre pkg e o repositório packages.termux.dev.

Pratique no terminal simulado

Missão 1 — instalar: rode pkg update e depois pkg install git. A última linha deve ser git instalado ✓.

Missão 2 — provoquer o erro: tente instalar um pacote que não existe (pkg install abacate) e veja o Unable to locate package abacate. Depois rode pkg search vim e pkg list-installed.

Resumo

  • pkg = apt do Termux; instala em $PREFIX (/data/data/com.termux/files/usr), não em /usr.
  • Fluxo sagrado: pkg update → pkg install … → pkg list-installed para conferir.
  • pkg search termo procura; pkg show NOME mostra detalhes; pkg upgrade atualiza tudo; pkg uninstall NOME remove.
  • pkg e apt são sinônimos no Termux.
  • Erro Unable to locate package X = nome errado ou falta pkg update — cheque com pkg search.
