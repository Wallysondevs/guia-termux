O que é este guia

Termux é um emulador de terminal + ambiente Linux para Android: ele instala um shell bash real num diretório privado do app (/data/data/com.termux/files) e traz um gerenciador de pacotes próprio (pkg, baseado no apt do Debian) que compila os programas para rodar no celular.

  • Base: instalação correta (F-Droid), storage, pkg/apt e primeiros comandos;
  • Celular como servidor: sshd, servidor web, banco local e adb com root;
  • Termux-API: bateria, SMS, GPS, câmera, lanterna e notificações pelo terminal;
  • Avançado: root real, proot-distro (Ubuntu dentro do Termux), automação e projetos práticos.
